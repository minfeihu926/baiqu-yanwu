# 百趣演武 自动抽牌

《明日方舟：终末地》「百趣演武」抽牌界面的自动化小工具，逐张抽牌：

- 抽到第 `n` 张时，若点数 5 的张数 `< n-1`（剩下位置全出 5 也凑不够 4 张）→ 立即放弃重抽；
- 抽满 5 张且至少有 4 张 5 点 → 停手，手牌保留，脚本退出；
- 抽满 5 张仍不足 4 张 → 放弃重抽。

**不点「开始挑战」，不参与战斗。**

> 非官方工具，与鹰角网络无关，使用风险自负。

## 下载

到 [Releases](https://github.com/minfeihu926/baiqu-yanyu/releases) 下载：

| 文件 | 说明 |
|---|---|
| `baiqu_yanyu.exe` | 单文件版，自带 Python 和依赖，双击或命令行运行 |
| `baiqu_yanyu_win64_portable.zip` | 便携版，解压即用；单文件版被杀软误报时使用 |

单文件版首次启动会解压到系统临时目录，慢 1~2 秒。exe 未签名，Windows Defender 可能误报。

## 使用

1. 游戏用**窗口化**运行（1280×720 或 1280×800 均可），进入「百趣演武」抽牌界面；
2. 先确认能正确识别：

   ```bat
   baiqu_yanyu.exe --check
   ```

   正常会输出 5 个卡槽和 `按钮 draw: (…)`；
3. 正式运行：

   ```bat
   baiqu_yanyu.exe
   ```

4. 凑够 4 张 5 后脚本自动退出，手动点「开始挑战」。

运行期间脚本会独占鼠标，游戏窗口需要在前台，`Ctrl+C` 可随时中断。

### 从源码运行

Windows + Python 3.9+：

```bat
python -m pip install -r requirements.txt
python baiqu_yanyu.py
```

也可以双击 `run.bat`（会自动补依赖）。

## 参数

| 参数 | 说明 |
|---|---|
| `--check` | 只截图识别，不点击 |
| `--rounds N` | 最多放弃重抽多少轮，默认 60 |
| `--hwnd 0x...` | 手动指定游戏窗口句柄 |
| `--image PATH` | 离线分析一张截图 |
| `--version` | 显示版本 |

## 判定逻辑

已抽 `n` 张、其中 5 点牌 `f` 张：

| 条件 | 动作 |
|---|---|
| `n = 5, f ≥ 4` | 停手 |
| `n = 5, f < 4` | 放弃重抽 |
| `n < 5, f < n-1` | 放弃重抽 |
| 其他情况 | 继续抽 |

识别方式：

- **卡槽**：用青色卡背做列投影，找出 5 个等距卡槽，翻开后按等间距推算；
- **是否翻开**：卡槽左上角同时满足「白底 > 25%」和「深色文字 > 5%」，避免把翻牌动画中的空白卡面当成 0 点；
- **是否 5 点**：`templates/digit5.png` 做多尺度归一化互相关，阈值 0.75；
- **按钮**：按颜色找中心（抽牌=青色、放弃=红色、确认=黄色），点击前校验游戏窗口是否在前台。

同一轮内牌数只增不减，已确认的 5 也不会因为某一帧漏识别而回退。

## 概率

按牌库 `6/6/6/6/10` 计算，5 张里至少 4 张 5 的概率约 **1.9%**，期望约 53 轮。
单轮 2~3 秒，平均 **2~3 分钟**出结果，运气差会更久。

如果目标只是拿满奖励（战力点 20 / 150000），`4,4,4,4,4`、`5,5,5,4,1` 等组合同样满足，
概率约 **14.6%**，可以直接改判定条件。

## 常见问题

**找不到游戏窗口**
运行 `python tools/probe_windows.py`，把输出发到 issue。脚本会按「类名 UnityWndClass + 标题含 Endfield」→「进程名 Endfield*.exe」→「Unity 窗口」匹配，最小化的窗口会自动还原。

**找不到抽牌按钮**
确认游戏停在抽牌界面、窗口完整在屏幕内、没有改 UI 缩放或使用滤镜；把 `--check` 的输出发到 issue。

**点击没反应**
脚本和游戏权限保持一致（游戏是管理员就用管理员运行脚本）；确认游戏在前台。

**跑很久**
4 张 5 本来就是小概率事件，属于正常；嫌慢可以改用战力点判定。

## 已知限制

- 只处理第一轮，不点开始挑战；
- 依赖当前游戏 UI 的布局与配色，大版本更新后可能需要重新校准 `BTN_SPECS` 和模板；
- 仅支持 Windows。
